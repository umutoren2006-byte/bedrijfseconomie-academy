# Bedrijfseconomie Academy

Nederlandstalig leerplatform voor mbo-studenten. **In ontwikkeling — geen productie-app.**

## Lokaal starten
Node.js 20+; voer `npm install` en `npm run dev` uit.

## Controles
`npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`.

## Stand van zaken
Responsive homepage, navigatie en informatieve `/start` en `/inloggen`-schermen. Geen werkende accounts, database, AI, workshops of oefeningen. De zichtbare voortgang is gelabelde demodata. De andere goedgekeurde schermen volgen later.

## Beveiliging
Geen echte leerlinggegevens, API-sleutels of betaalde services toevoegen. Alleen ontwikkelen op de featurebranch; niet mergen zonder toestemming.
